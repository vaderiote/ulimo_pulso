# Último Pulso

RPG top-down post-apocalíptico desarrollado en GameMaker Studio 2.

## Historia
Un superviviente llamado Kaleen recorre un mundo destruido por una invasión alienígena que colapsó toda la tecnología. A medida que avanza, descubre fragmentos de su pasado y su verdadero destino.
